## Long description

**Insait Edit Code Editor** is designed for fast creation and editing of scripts and source code in many programming languages.

The app is lightweight, fast, and productivity-focused, with full built-in integration with **Git** and **GitHub**.

### What the app is for

- **Creating and editing scripts** — open, create, and quickly edit scripts and files in many programming languages.
- **Git integration done right** — full Git and GitHub integration: clone repositories, track changes, and create commits through a convenient Git panel.
- **Fast editing without code suggestions** — the editor does **not** have code-suggestion features (no IntelliSense/autocomplete). This keeps it extremely lightweight and deterministic, ideal for quick edits on the fly.
- **Learning to program** — thanks to a simple and clear interface, the app is great for **learning programming-language syntax**, and for beginners who are learning to write code.

### Key features

- Fast, lightweight interface with file tabs.
- **Git/GitHub integration**: repository cloning, creating new repositories, tracking state, commits, editing remotes, GitHub authentication (OAuth Device Flow).
- Built-in **terminal** for running commands and scripts.
- Left panel: file explorer (project tree), Git commits, and project settings.
- Registering file associations as the default app for a large set of extensions.
- Live preview of designs.

### System requirements

- Windows 10 (version 1903 or later) or Windows 11, 64-bit.
- .NET Runtime 10.
